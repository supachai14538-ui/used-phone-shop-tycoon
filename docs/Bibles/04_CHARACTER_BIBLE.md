# 👤 CHARACTER BIBLE
# Used Phone Shop Tycoon

Version: 1.0

Status: Master Character Design Guide

---

# Overview

The Character Bible defines the visual identity, structure, behavior, and design standards for every human character in the game.

Every character must follow this document.

The objective is to ensure visual consistency and support future AI-generated assets.

---

# Character Philosophy

Characters should feel

Friendly

Approachable

Expressive

Realistic enough to feel believable

Stylized enough to remain timeless

Players should remember customers as people,

not as random NPCs.
