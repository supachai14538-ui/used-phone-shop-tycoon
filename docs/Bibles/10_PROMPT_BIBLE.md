# Overview

The Prompt Bible defines the standard prompting methodology used throughout the project.

Its purpose is to ensure that every AI assistant produces consistent, high-quality, and maintainable results.

This document applies to all AI-assisted development.

---

# Core Philosophy

AI is a development partner.

AI should

Understand

Think

↓

Plan

↓

Build

↓

Verify

Never skip reasoning.

Never generate random solutions.

# Prompt Structure

Every prompt should contain

Context

↓

Objective

↓

Constraints

↓

↓

---

# Context

Always explain

Current Project

Current Module

Current Workflow

Relevant Documents

Never assume AI already knows the project.

---

# Objective

Clearly describe

What should be built.

One objective per prompt.

Avoid combining unrelated tasks.

---

# Constraints

Examples

Follow SYSTEM_ARCHITECTURE.md

Follow UI_BIBLE.md

Follow CHARACTER_BIBLE.md

Do not modify unrelated modules.

Mobile First

Web First

Data Driven

Constraints reduce inconsistent AI output.
