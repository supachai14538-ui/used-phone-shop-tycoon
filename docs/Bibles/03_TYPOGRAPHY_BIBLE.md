# 🔤 TYPOGRAPHY BIBLE
# Used Phone Shop Tycoon

Version: 1.0

Status: Master Typography Guide

---

# Design Philosophy

Typography is one of the most important communication tools in the game.

Players should immediately understand prices, profits, phone conditions, and business information without visual confusion.

Readability is always more important than artistic style.

---

# Typography Principles

The typography should be

- Clean
- Modern
- Easy to read
- Mobile-first
- Business-oriented

Avoid decorative fonts.

# Number Formatting

Numbers should always be

- Bold
- Easy to scan
- Right-aligned where appropriate

Examples

Cash

Profit

Repair Cost

Market Price

Business Value

---

# Money Display

Currency should always include

Currency Symbol

Thousands Separator

Consistent Decimal Format

Example

฿12,500

Never display

12500

---

# Percentage Display

Examples

95%

82%

34%

Always include

%

Phone condition should never omit the percentage symbol.

---

# Alignment

Titles

Left

Body

Left

Money

Right

Statistics

Center or Right

Buttons

Center

---

# Line Height

Comfortable reading.

Avoid dense paragraphs.

Provide enough spacing for touch devices.

---

# Spacing

Large spacing between sections.

Medium spacing inside cards.

Consistent padding across all screens.

---

# Button Typography

Text should be

Bold

Centered

Short

Action-oriented

Examples

Buy

Sell

Repair

Accept

Reject

End Day

Avoid long button labels.

---

# Receipt Typography

Receipts are a signature element of the game.

Receipt typography should resemble a real POS receipt.

Use

Simple

Compact

Readable

Transaction values should stand out.

---

# Dashboard Typography

The dashboard should prioritize

Cash

Today's Profit

Reputation

Current Day

Inventory Count

Important values should always be visually stronger than labels.

---

# Inventory Typography

Display

Brand

Model

Condition

Selling Price

Repair Status

Information should be scannable in less than 3 seconds.

---

# Customer Dialogue

Dialogue should

Be short

Natural

Easy to read

Avoid long paragraphs.

---

# Accessibility

Minimum readable text size.

High contrast.

Avoid thin fonts.

Support both English and Thai.

---

# Responsive Typography

Mobile First

Text should scale naturally across

Phones

Tablets

Desktop

Typography should remain readable without zooming.

---

# Future Expansion

Dark Mode Support

Dynamic Font Scaling

Accessibility Mode

Large Text Mode

Language Packs

---

# Typography Rules

Never use more than

2 Primary Fonts

Avoid excessive font weights.

Maintain consistent spacing.

Typography should support gameplay,

not distract from it.

---

# Final Principle

Good typography is invisible.

Players should focus on running the business,

not on trying to read the interface.

Every word,

every number,

and every label

should help players make faster and smarter decisions.
