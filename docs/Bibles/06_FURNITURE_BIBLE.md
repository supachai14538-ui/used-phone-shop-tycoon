# Used Phone Shop Tycoon

---

# Overview

The Furniture Bible defines the visual language, categories, functions, and placement rules for every furniture item in the game.

Furniture should not only decorate the shop.

Every furniture piece should support gameplay and business progression.

---

# Design Philosophy

Furniture represents business growth.

Every new furniture item should make the shop feel

- More professional
- More organized
- More successful

Furniture should always have purpose.

# Placement Rules

Furniture must align to the shop grid.

No overlapping.

No floating objects.

Walkways should remain accessible.

---

# Grid System

Every furniture item snaps to the grid.

Rotation

0°

180°

270°
