# 🌍 ENVIRONMENT BIBLE
# Used Phone Shop Tycoon

Version: 1.0

Status: Master Environment Design Guide

---

# Overview

The Environment Bible defines the visual identity, atmosphere, architecture, lighting, and world-building standards for the game.

Every scene should support the feeling of running a successful second-hand phone business.

The environment should feel alive without distracting the player.

---

# Design Philosophy

The environment exists to support gameplay.

Players should immediately understand

- Where they are
- What they can interact with
- How successful the shop has become

Environment should never overpower gameplay.
