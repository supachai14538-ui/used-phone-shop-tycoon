# Used Phone Shop Tycoon

Version: 1.0

Status: Master Design Guide

---

# Design Philosophy

The interface should make players feel like they are running a real second-hand phone shop.

The UI should be

- Friendly
- Clean
- Readable
- Business-focused
- Mobile-first

Players should spend their time making business decisions, not figuring out how the interface works.

# Design Principles

Every UI element should follow these rules

- Easy to understand
- Easy to touch
- Easy to read
- Fast to recognize

Avoid unnecessary visual effects.

Gameplay comes before decoration.

---

# Visual Style

- Small retail shop
