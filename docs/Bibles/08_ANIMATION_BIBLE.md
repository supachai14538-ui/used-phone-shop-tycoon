# 🎬 ANIMATION BIBLE
# Used Phone Shop Tycoon

Version: 1.0

Status: Master Animation Guide

---

# Overview

The Animation Bible defines the animation principles, timing, transitions, and motion language used throughout the game.

Animations should improve usability, reinforce player feedback, and make the shop feel alive.

Animations should never delay gameplay.

---

# Animation Philosophy

Animation exists to support gameplay.

Every animation must answer at least one question.

Does it improve readability?

Does it improve feedback?

Does it improve immersion?

If the answer is "No",

the animation should not exist.
